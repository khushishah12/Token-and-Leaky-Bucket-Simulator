In packet-switched networks, unregulated burst traffic causes buffer overflow, packet drops, and severe latency. Traffic Shaping algorithms regulate average transmission rate and burstiness before packets enter the subnet. Explore how Token Bucket and Leaky Bucket operate step-by-step with real-time mathematical breakdowns.

Burst-Friendly Shaper

Token Bucket Algorithm

Controls traffic by generating and consuming tokens. Packets can be transmitted when sufficient tokens are available, allowing controlled bursts while enforcing an average rate limit.

  • ✓ Allows short bursts at full line speed
  • ✓ Discards tokens (not packets) when bucket overflows
  • ✓ Tokens replenish at a steady constant rate \(R\)

Constant-Rate Shaper

Leaky Bucket Algorithm

Controls traffic by transmitting packets at a strictly fixed output rate. Incoming packets are placed in a finite queue, and excess packets are dropped when the buffer overflows.

  • ✓ Converts bursty traffic into a smooth, constant stream
  • ✓ Fixed leak rate regardless of arrival spikes
  • ✓ Drops packets when queue capacity is exceeded

Key Concept at a Glance

Token Bucket Model

Bucket holds: Tokens (credits for transmission)

Input: Periodic tokens generated + variable packets

Output: Bursty or steady packets (if tokens exist)

Overflow action: Excess tokens are discarded; packets wait or drop

Leaky Bucket Model

Bucket holds: Packets / Raw Data waiting in FIFO queue

Input: Bursty, irregular packet arrivals

Output: Strictly constant packet rate leaking from bottom

Overflow action: Excess incoming packets are dropped immediately

5. Comprehensive Algorithm Comparison Matrix

Feature / Metric Token Bucket Algorithm Leaky Bucket Algorithm
Traffic Handling Allows controlled bursts of traffic up to the bucket capacity (\(C\)). Smooths traffic into a rigid, constant-rate stream.
Output Transmission Rate Variable: can transmit at peak interface line speed if sufficient tokens exist. Fixed: data leaves bucket strictly at rate \(L\) units per time step.
Buffer Contents Holds virtual tokens (transmission permissions). Holds actual packets / data units in a FIFO buffer.
Overflow Action Excess tokens are discarded with zero data loss when bucket is full. Excess packets arriving to a full queue are dropped.
Burst Transmission Condition Max burst size = \(C + R \cdot \Delta t\) (instantaneous burst = \(C\)). Burst is buffered and serialized over multiple time intervals.
Packet Delay / Latency Low latency for burst packets when tokens are pre-accumulated. Higher queuing latency because packets must wait for the fixed leak rate.
Typical Real-World Use Bursty applications (HTTP/web browsing, dynamic API rate limiting, video streaming). Constant bit-rate streams (VoIP voice calls, ATM networks, strict ISP policing).
